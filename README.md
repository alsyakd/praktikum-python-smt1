# Praktikum Python Semester 1

Python practical exercises and assignments for **Semester 1** programming course (Praktikum PAK Iwan).

## Project Structure

```
praktikum-python/
├── latihan/          # Practice exercises (5 meetings)
│   ├── pertemuan_1.py              # Hello World
│   ├── pertemuan_2_tipeData.py     # Variables, data types, casting, input
│   ├── pertemuan_3_*.py            # Arithmetic & comparison operators, temperature conversion
│   ├── pertemuan_4_*.py            # Logical operators, if/elif/else, comparisons
│   └── pertemuan_5_*.py            # Loops: for, while, break, continue, pass
├── tugas/            # Assignments
│   ├── identitas.py                # Personal identity display
│   ├── literalData-1.py            # Literal data exercise 1
│   ├── literalData-2.py            # Literal data exercise 2
│   ├── literalData-3.py            # Literal data exercise 3
│   ├── operasiAritmatika.py        # Calculate volume, area, and perimeter of a rectangular block
│   ├── ganjilGenap.py              # Display odd and even numbers from 1 to 50
│   ├── bilanganPrima.py            # Display prime numbers from 1 to 100
│   └── kategoriUsia.py             # Categorize user input age group
```

## Topics Covered

| Pertemuan | Topic |
|-----------|-------|
| 1 | Hello World |
| 2 | Variables, Data Types (int, float, string, bool, complex), Casting, User Input |
| 3 | Arithmetic Operators, Comparison Operators, Temperature Conversion |
| 4 | Logical Operators, If/Elif/Else Conditionals |
| 5 | Loops (for, while), Break, Continue, Pass |

## How to Run

```bash
python latihan/pertemuan_1.py
python tugas/identitas.py
```
